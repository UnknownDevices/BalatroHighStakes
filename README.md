# High Stakes

Gold Stake doesn't cut it for you anymore? High Stakes adds plenty more Stakes after it, four of which bring a new Joker Sticker to the shop.

## Stakes

| Stake        | Effect                                                                                                            |
| ------------ | ----------------------------------------------------------------------------------------------------------------- |
| **Gray**     | Shop can have **Heavy** Jokers                                                                                    |
| **Brown**    | Boss Blind on Ante 6 or 7 is a Pit Blind _(requires [All in Jest](https://github.com/survovoaneend/All-In-Jest))_ |
| **Pink**     | Shop can have **Linked** Jokers                                                                                   |
| **Teal**     | Shop can have **Fragile** Jokers                                                                                  |
| **Platinum** | Shop can have **Treacherous** Jokers                                                                              |

## Stickers

- **Heavy**: Can't be moved (and other Jokers can't be moved past it).
- **Linked**: All Linked Jokers are sold or destroyed together.
- **Fragile**: 1 in 10 chance to be destroyed at end of round.
- **Treacherous**: +20% required score each round.

## Settings

In **Mods → High Stakes → Config**:

- Disable any of the new Stakes.
- Rework Blue Stake to take on Pink Stake's effect instead of its -1 Discard, and disable Pink Stake.
- Change how often each sticker appears, vanilla's Eternal, Perishable and Rental included.

## Installation

1. Install [Lovely](https://github.com/ethangreen-dev/lovely-injector) and [Steamodded](https://github.com/Steamodded/smods) (v26.1002.0 or newer), following their instructions
2. Download this mod from this Github page (**Code → Download ZIP**, or from Releases).
3. Extract it into your Mods folder, so the folder holding `high_stakes.json` sits directly inside `Mods`:
   - **Windows:** `%AppData%\Balatro\Mods\Highstakes`
   - **macOS:** `~/Library/Application Support/Balatro/Mods/HighStakes`
4. Launch the game and it's done.

Remember to enable the Blue Stake rework in the mod's configuration if you want it, since that's off by default.
